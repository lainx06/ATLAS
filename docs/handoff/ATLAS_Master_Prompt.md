3. Keep five evidence modules: split integrity, preprocessing fit provenance, independent metric/baseline comparison, temporal availability, and robustness across predeclared seeds/groups.
4. Limit automated execution to small supported tabular classification projects and a documented adapter contract. Static source inspection produces suspicions; instrumented execution and independent evaluation establish bounded facts. Unsupported code receives NOT_ASSESSED, not PASS.
5. Preserve immutable input snapshots, evaluation policy, and held-out labels. The agent may change a candidate project, not the evaluator or pass criteria. Evaluate predictions against labels owned by the trusted evaluator. Do not select changes on final test performance.
6. Execute candidate code in disposable restricted containers with no credentials or network, bounded CPU/memory/processes/time, and only required mounts. A Git worktree is a checkpoint, not a sandbox. Docker is the initial implementation, not the only possible isolation mechanism. An alternative must enforce the same execution contract. A temporary directory, subprocess timeout, shell=False, or reduced environment alone is not a sandbox. If execution isolation is unavailable, use trusted deterministic fixtures and mark live patch execution blocked; never silently execute generated arbitrary code on the host.
7. Use local JSON procedure records and SQLite/JSONL run metadata, not a vector database. The model may propose a procedure; code validates prerequisites and evidence before admission. A reusable procedure is an explicit workflow, not model-weight learning.
8. Begin with seeded, honestly labeled synthetic fixtures; add a licensed real-data example and an untouched evaluation case. Do not call synthetic sensor data real sEMG. Avoid promising a large accuracy drop or token savings until measured.
9. Host only curated, bounded demo workloads publicly. Do not expose arbitrary repository upload/code execution. Keep API credentials server-side. Provide a runnable local test build, recorded example mode, and an exportable evidence report.
